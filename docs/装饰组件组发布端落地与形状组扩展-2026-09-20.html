由链路推导出的组件库铁律

预览与发布消费的是同一份 component.config，走的是同一套 codegen。 因此「编辑区所见」与「发布后所得」要一致，只能靠两端共用同一份取值口径（纯函数）， 任何一处字面量被写进两份代码，迟早分叉。本轮的装饰组件组就是这条铁律的最大反面教材（见下）。

二、P0 缺陷：装饰组件组在发布端不存在

现象装饰组件组拖进画布能正常显示；点预览只看到橙色「xxx (codegen 待实现)」占位块；发布出去的站点上该组件什么都没有。
根因src/codegen/components/index.ts 的注册表里没有任何 decoration-*； 未注册类型走 engine.ts 的 generateUnsupportedComponent：预览分支输出占位块（:358-366）， 非预览分支输出空 div（:368-372）。

三、实现：把几何收口成「一份声明」，两端各取所需

单纯给 20 个形状补 20 份 codegen 字面量是错的解法 —— 那等于把几何写进第二处，只是把分叉推迟到下一次改版。 本轮的做法（沿用本仓库既定的「唯一取值口径」范式）：

文件角色状态
src/editor/data/decorationShape.ts 唯一取值口径：decorationShape(kind, config, opts) 输出 DecorShapeSpec （viewBox / preserveAspectRatio / defs 渐变 / 图元列表 / 自动贴合尺寸 / 关键帧）； 另含 shapeSpec()（形状组映射）、SHAPE_KIND_OPTIONS、SHAPE_SHADOWS、 发布端字符串化工具 svgAttrText/svgPrimitiveText/svgDefText 新建
src/editor/renderers/DecorationShapeRenderer.tsx 编辑区：DecorationSvg（图元 → React 元素，装饰组与形状组共用）+ createDecorationShapeRenderer(kind) 工厂（保留 DecorationWrapper 动画与 _autoFitSize 回写） 新建
src/codegen/components/decoration.ts 发布端：renderDecorSpec(spec, ctx, extraBoxCss) 单一发射器 + decorationShapeCodegen（20 个形状共用）+ DECORATION_SHAPE_KINDS 清单 新建
20 个 *DecorationRenderer.tsx 由各自实现几何（平均 60~100 行）瘦身为 1 行绑定：export const X = createDecorationShapeRenderer("decoration-x") 重构
src/codegen/components/index.ts 按清单批量注册 20 个形状的 codegen 修复

顺手修掉一个「面板说谎」的既有问题：

decoration-arrow 的 arrowShape / arrowCount 两个字段此前渲染器完全不读

面板提供「菱形双向 / 三角箭头」与「箭头数量 1~10」，旧渲染器恒定画三角头、恒定 1/2 个箭头。 现在两端都按面板渲染：triangle 保持原几何（30° 半角），diamond 画出真正的菱形箭头， arrowType=chain 沿线路均匀排布 arrowCount 个箭头。

四、形状组件组扩展（shape 1.0.0 → 2.0.0）

形状组此前只有 3 种形状、5 个属性；现在复用装饰组的几何，形状与属性都补齐：

分组字段
内容形状类型（矩形/圆形/椭圆/线条/三角/菱形/五角星/正多边形/十字/虚线框）、边数、角数、内径比、笔画粗细（十字）、线条方向、虚线段长/间隔
填充渐变填充开关、填充色、渐变起止色、渐变方向（含径向）

八、可复用要点

  • 补发布端实现的第一原则：先把几何/取值抽成纯函数口径，再让两端去读它；直接写第二份字面量等于制造下一次分叉。
  • 「自然尺寸内容」与「铺满型内容」的取舍：形状/图标/评分/徽标类保持比例居中（preserveAspectRatio="meet" 或 scaleStageCss 等比缩放）； 矩形/椭圆/线条/网格类铺满（preserveAspectRatio="none"）—— 用错会得到「圆被拉成椭圆」这类结果。
  • 属性栏不许说谎：面板给了选项，渲染器与 codegen 就必须读它（本轮修掉箭头 arrowShape/arrowCount）。
  • 缩放/居中的验证要在发布端做：编辑器画布正确不代表发布页正确（rate 曾出现「编辑区缩放、发布端固定」的历史缺陷）。
  • 验证配方沿用既有两档：--dump-dom 静态几何探针（本项目本轮用法）+ CDP 真实鼠标事件（证明 :hover 类规则没被 inline 压死）。探针文件用完即删。
