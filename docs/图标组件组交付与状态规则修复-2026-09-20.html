二、跨组基础设施收口（影响的不只是图标）

2.1 抽公共底座 editor/data/cssDecls.ts

CssDecls / cssText / styleAttr / kebab / escapeHTML / escapeAttr / num / clampNum / str / bool / alignToFlex / alignToText 原先在各「唯一取值口径」文件里各复制一份。同一批工具复制 N 份，一旦有人只改其中一份，两端行为就会悄悄分叉。 现在这些原语只此一份，tableStyle.ts 改为重导出（既有引用不受影响）。

2.2 缩放骨架的声明口径收口（修掉一处真实两端分叉）

修前编辑区舞台 flex:1 1 auto;width:100%…，发布端骨架 width:100%;height:100%… —— 同一份配置，两端舞台的 flex 行为不同；内层同理（编辑区自带 transform-origin/flex-shrink，发布端靠骨架字符串拼）。
修后scaleStageCss(align) + scaleInnerBaseCss() 移入 editor/data/scaleFit.ts，发布端 scaleFitStage 改为读它 → 逐字一致。 组件自己的内层声明经 innerStyle 追加，顺序恒为「公共在前、组件声明在后」。

另给 scaleFitScript 加了 st.__wcFit = fit：接口数据到达后内容尺寸可能变化， 组件可以在重建内容后主动重新适配缩放（图标族已在用）。

2.3 统一的三层缩放结构

容器（铺满 + 裁剪）→ 舞台（100%，脚本量它算系数）→ 内层（自然尺寸，只被 transform 缩放）

用 transform 而不是逐个缩放子元素字号：只触发合成、不引起重排，拖动框连续改尺寸也不掉帧； 且子元素 CSS 只需按自然尺寸写一次。系数恒由 fitFactor（两端同一实现）算出。

三、真实浏览器实测揪出的 2 个真 bug

这两条单测抓不到（jsdom 不实现 CSS 级联），且静态字符串断言也会漏， 是启动 headless Chrome + CDP Input.dispatchMouseEvent 真实鼠标移入后才暴露的。

3.1 已修 静态 transform 写在 inline → 悬浮放大永远失效

修前

<span data-icon-rot="1"
     style="…;transform:rotate(45deg)">
/* 类规则 */
.ic-x-rot:hover{transform:rotate(45deg) scale(1.3)}

/* inline 恒胜过非 !important 的类规则 */
→ 鼠标悬浮：毫无反应

修后

<span data-icon-rot="1" class="ic-x-rot"
     style="display:inline-flex;transition:…">

/* 静态与悬浮成对进类规则层 */
.ic-x-rot{transform:rotate(45deg)}
.ic-x-rot:hover{transform:rotate(45deg) scale(1.3)}

关键约束：rotate / flip 是「静态值」，但当它同时出现在状态规则里时， 它就不能再进 inline。编辑区用 MUI sx（编译成类规则，非 inline）承载等价的一对值， 两端取值都来自 iconStaticTransform() / iconHoverTransform()。

3.2 已修 底色写进 inline → 悬浮高亮彻底失效

图标列表的条目底色与图标按钮的按钮底色，既是静态值又是悬浮态的切换目标。 原先写进 inline，导致 .{-it}:hover{background-color:…} 被永久压死。 现改为由类规则承载（iconListRules() / iconButtonRules()）， 编辑区由 sx 承载同一对取值。

3.3 附带修正 实心按钮的悬浮色原本等于底色

派生的悬浮色原本就取主题色本身 → 实心按钮悬浮时底色不变、零反馈。 改为 darkenHex(color, 0.12) 调暗 12%；描边/文字形态则用主题色 12% 透明度薄底。 用户显式配置悬浮色时一律以配置为准。

六、动态数据接入方式（两种，都可用）

接入方式配置编辑区发布端
非认证（纯静态 / 公开接口） dataMode: "api" + apiUrl，authEnabled 留空或 false useApiDataFetch dataLoaderScript（不注入 Token）
认证（跟随站点登录态） authEnabled: true（注入 Token）或留空（跟随站点全局认证态） useApiDataFetch 透传三态 → websiteAuthStore dataLoaderScript 读 __WC_AUTH_ENABLED / __WC_TOKEN_*，并监听 auth-state-change 事件自动重取
全局数据源绑定 dataSourceId 命中站点级数据源 绑定后忽略自带配置 引擎层 withEffectiveConfig() 统一合并 —— 任何新组件自动获得，组件 codegen 无需自理

接口模式下数据在浏览器才到达，图标无法用编译期 renderMenuIcon 内联。 为此在 codegen/iconPipeline.ts 新增了与编译期行为对齐的运行时渲染器 RUNTIME_ICON_RENDERER_JS（renderIcon）与数据归一 RUNTIME_ICON_ITEMS_JS（toItems），配合 MATERIAL_ICON_PATHS 注入。 首屏先用编译期内容打底（与编辑区 resolveIconItems 的回落一致），避免闪空。
